# Iniciando-no-Python
Meus primeiros passos na programação, começando pela lógica de programação básica.

## Sistema de Materiais por Projeto

Este repositório também contém, em [`sistema-materiais/`](sistema-materiais/),
uma aplicação web (sem instalação necessária) para controle de materiais de
obra organizado por projeto — cada projeto com seus próprios materiais,
fotos, pendências, indicadores, relatórios e histórico. Basta abrir
`sistema-materiais/index.html` no navegador. Detalhes da arquitetura em
[`sistema-materiais/README.md`](sistema-materiais/README.md).
